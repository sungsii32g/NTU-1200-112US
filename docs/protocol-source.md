## 1. 物理層與通訊介面定義

### 1.1 串列參數
* **鮑率 (Baud Rate)**：`9600 bps`
* **資料長度 (Data Bits)**：`8 bits`
* **同位檢查 (Parity)**：`None (無)`
* **停止位元 (Stop Bits)**：`1 bit`
* **流量控制 (Flow Control)**：`None (無硬體/軟體流控)`
* **協定編碼**：標準 ASCII 字元
* **指令結束字元 (Delimiter)**：ASCII Carriage Return (`\r`, `0x0D`)

### 1.2 原廠 RJ11 (6P4C) 與 DB9 接線對照表 (經原廠工程圖紙核定)

```
NTU-1200-112US Remote Port (RJ11 6P4C)                標準 RS-232 (DB9 公頭/母頭)
┌──────────────┐                                      ┌────────────────────────┐
│   RJ11       │                                      │   DB9                  │
│              │                                      │                        │
│ Pin 2 (Rx) ──┼─────────────────────────────────────►│ Pin 3 (TXD)            │
│ Pin 3 (GND) ─┼─────────────────────────────────────►│ Pin 5 (GND)            │
│ Pin 4 (Tx) ──┼─────────────────────────────────────►│ Pin 2 (RXD)            │
└──────────────┘                                      └────────────────────────┘
```

> [!CAUTION]
> **重要隔離防護**：
> 手機端或微控制器端連接時，中間**必須搭載光耦電氣隔離型 USB 轉 RS-232 轉換晶片 (如 FT232RL / CH340 隔離版)**，以防逆變大功率負載切換時之突波損壞主機。

## 2. 嚴格輪詢時序常數 (硬性約束)

| 時序項目 | 數值 | 說明 |
| :--- | :--- | :--- |
| **Request-to-Request 間隔** | **$\ge 500\text{ ms}$** | 手冊明確規範主機向逆變器發送兩次請求之間的最小間隔時間，不可過度頻繁輪詢 |
| **Inter-packet delay** | **$\ge 10\text{ ms}$** | 指令間最小靜默時間 |
| **典型回應延遲** | **$\le 15\text{ ms}$** | 逆變器處理與回傳字串之典型時間 |
| **主機超時等待 (Timeout)** | **$150\text{ ms}$** | 若超過 150ms 未收到回傳，判定該次請求逾時 |
| **過期警告門檻 (Stale Data)** | **$1500\text{ ms}$ (3次未收到)** | 連續 3 個週期無法取得有效回傳時，UI 數值變灰並標記「STALE / 資料過期」 |

## 3. 指令集語法與規範 (Command Set)

### 3.1 查詢指令 (Read-Only)
| 指令 | 語法 | 說明 | 寫入副作用 |
| :--- | :--- | :--- | :--- |
| **`Q`** | `Q\r` | 查詢即時電力遙測數據 (電壓、負載、溫度、位元旗標) | 無，安全查詢 |
| **`I`** | `I\r` | 查詢設備型號、額定規格與韌體版本 | 無，安全查詢 |

### 3.2 控制指令 (Write / Control)
> [!WARNING]
> 所有寫入控制指令在軟體中預設受 `CapabilityFlags` 鎖定。必須滿足：**工程控制開鎖 + 1.5 秒長按 + 二次確認彈窗**，且**不可自動重試**，發送後立即發送 `Q\r` 回讀狀態確認。

| 指令 | 語法 | 說明 | 參數範例 |
| :--- | :--- | :--- | :--- |
| **`C`** | `C <1/0> [CS]\r` | 逆變器輸出開關控制 | `C 1\r` (開啟), `C 0\r` (關閉) |
| **`W`** | `W <1/0> [CS]\r` | 節能模式開關 | `W 1\r` (啟用省電), `W 0\r` (關閉省電) |
| **`pU`** | `pU\r` | 參數解鎖指令 (執行 V 配置前必先送出) | `pU\r` |
| **`V`** | `V <WWW> <0FF> [CS]\r` | 設定輸出電壓與頻率 | `V 110 060 8B\r` |

## 4. `Q` 回應字串解析規格 (49 位元組格式)

### 4.1 封包語法結構
```text
(VVV.V QQQ SS.S BBB.B TT.T MMM.M RR.R DDD.D PPP b0b1b2b3b4b5b6b7b8b9b10b11b12b13b14b15b16b17b18)\r
```

### 4.2 欄位詳細定義

| 欄位標記 | 欄位名稱 | 單位 | 正常數值範例 | NTU-1200-112US 門檻與說明 |
| :--- | :--- | :--- | :--- | :--- |
| `VVV.V` | 交流輸出電壓 (AC Out) | V | `110.0` | 正常 110.0V (±3%) |
| `QQQ` | 輸出負載百分比 (Load %) | % | `035` | 0% ~ 100% (1200W 對應 100%) |
| `SS.S` | 類比負載百分比 | % | `035.0` | 輔助參考 |
| `BBB.B` | 電池直流電壓 (DC Batt) | V | `012.6` | 正常 10.0V~16.5V，低壓警告 11.0V，切斷 10.0V |
| `TT.T` | 散熱器溫度 (Temp) | °C | `038.5` | 機內散熱片溫度 |
| `MMM.M` | 市電輸入電壓 (Grid In) | V | `110.0` | 市電旁路存在時約 110V，斷電時 000.0V |
| `RR.R` | 輸出頻率 (Frequency) | Hz | `060.0` | 60.0 Hz |
| `DDD.D` | 直流母線電壓 (DC Bus) | V | `162.0` | 內部升壓母線 |
| `PPP` | 保留/狀態指標 | - | `000` | 保留欄位 |
| `b0~b18` | 19位元二進制狀態字串 | Bit | `1011000000000000000` | 詳細見下表 |

### 4.3 狀態旗標 (`b0` ~ `b18`) 位元對照表
* `b0`：**逆變輸出致能** (`1` = 逆變電路工作中, `0` = 待機/關閉)
* `b1`：**UPS 市電旁路供電中** (`1` = 負載直接由市電旁路供電, `0` = 逆變供電)
* `b2`：**市電交流輸入正常** (`1` = 市電市網輸入正常在範圍內, `0` = 市電斷電/異常)
* `b3`：市電充電狀態指示
* `b4`：太陽能充電狀態指示
* `b5`：**節能模式啟用中** (`1` = 啟動省電模式)
* `b16`：**逆變器故障告警** (`1` = Fault 異常)
* `b17`：**內部 EEPROM 錯誤** (`1` = 異常)
