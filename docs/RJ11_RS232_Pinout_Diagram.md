# MEAN WELL NTU-1200-112US RJ11 遠端埠與 RS-232 實體接線圖解指南

> **核定依據**：明緯原廠使用手冊與 Remote Port (RJ11 6P4C) 腳位工程圖紙

---

## 1. 雙端腳位對照總表

| 訊號名稱 | NTU-1200 Remote Port (RJ11 6P4C) | 標準 RS-232 (DB9) 腳位 | 訊號流向說明 |
| :--- | :--- | :--- | :--- |
| **Rx (逆變器接收)** | **Pin 2** | **Pin 3 (TXD)** | 手機/主控發送指令 ──► 送入 NTU RJ11 Pin 2 |
| **GND (信號地)** | **Pin 3** | **Pin 5 (GND)** | 雙端共地（透過光耦與主控端隔離） |
| **Tx (逆變器發送)** | **Pin 4** | **Pin 2 (RXD)** | 逆變器回傳數據 ──► 進入手機/主控接收 Pin 2 |

> **注意**：RJ11 插頭為 6P4C（6 個卡槽位置，中間 4 根金屬彈片）：
> - 彈片面朝向自己、金屬腳位從左到右編號為 1, 2, 3, 4, 5, 6
> - Pin 1: 空腳 (NC)
> - Pin 2: Rx (接收)
> - Pin 3: GND (地)
> - Pin 4: Tx (發送)
> - Pin 5, 6: 空腳 (NC)

## 2. 兩種模式的硬體接線架構圖

### 【模式一：ESP32-S3 嵌入式控制面板】
```
NTU-1200-112US (RJ11)         光耦隔離 RS-232 轉 TTL (3.3V)         ESP32-S3 開發板
Pin 2 (Rx) ───────────────────► RS232-TXD
Pin 3 (GND) ──────────────────► RS232-GND
Pin 4 (Tx) ───────────────────► RS232-RXD
                                TTL-TXD ──────────────────────────► GPIO 18 (RX2)
                                TTL-RXD ◄────────────────────────── GPIO 17 (TX2)
                                TTL-GND ──────────────────────────► GND
                                TTL-VCC ◄────────────────────────── 3.3V
```
