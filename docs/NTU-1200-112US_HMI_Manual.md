# MEAN WELL NTU-1200-112US 觸控控制面板開發專案工程指南 (HMI System)

> **目標機型**：MEAN WELL NTU-1200-112US (12Vdc 輸入轉 110Vac 60Hz 輸出，額定 1200W，峰值 2000W，美規插座，UPS/旁路功能)  
> **核心硬體**：ESP32-S3 (8MB Flash, 8MB PSRAM) + 3.5 吋 IPS 電容觸控螢幕 (480×320)  
> **圖形函式庫**：LVGL 8.3 + LovyanGFX  
> **通訊協定**：明緯原廠 Remote Port (RJ11 6P4C) RS-232 ASCII 協定 (9600-8-N-1)

---

## 1. 系統硬體架構與電氣隔離設計

### 1.1 RJ11 (6P4C) 遠端埠接線定義

明緯 NTU-1200 的 Remote port 為 RJ11 (6P4C) 母座，內部訊號為標準 EIA/TIA-232 電平（±5V ~ ±12V）。**絕對不能直接連接 ESP32 的 3.3V GPIO，否則微控制器將瞬間燒毀！**

```
                ┌─────────────────────────────────┐
                │   MEAN WELL NTU-1200-112US      │
                │        Remote Port              │
                │         RJ11 (6P4C)             │
                └────────────────┬────────────────┘
                                 │
                   Pin 2: Rx ────┼────────┐
                   Pin 3: GND ───┼─────┐  │ (RS-232 電平 ±5V~±12V)
                   Pin 4: Tx ────┼──┐  │  │
                                 │  │  │  │
        ┌────────────────────────┴──┼──┼──┴────────────────────────┐
        │   【光耦隔離 RS-232 轉 TTL 轉換模組】                      │
        │   (切斷大電流高頻開關接地迴路 Ground Loop 與突波)          │
        │                                                          │
        │   RS232-TXD <──── RJ11 Pin 2 (NTU Rx)                    │
        │   RS232-GND <──── RJ11 Pin 3 (NTU GND)                   │
        │   RS232-RXD <──── RJ11 Pin 4 (NTU Tx)                    │
        │                                                          │
        │   TTL-TXD ──────────────────────────► ESP32 GPIO 18 (RX2)│
        │   TTL-RXD ◄────────────────────────── ESP32 GPIO 17 (TX2)│
        │   TTL-GND ──────────────────────────► ESP32 GND          │
        │   TTL-VCC ◄────────────────────────── ESP32 3.3V         │
        └──────────────────────────────────────────────────────────┘
```

#### 接線對照表

| 功能定義 | NTU 遠程端口 (RJ11) | 標準 DB9 腳位 | 光耦隔離 RS-232 端 | 轉接至 ESP32-S3 (3.3V TTL) |
| :--- | :--- | :--- | :--- | :--- |
| **NTU 接收 (Rx)** | **Pin 2** | Pin 3 (TXD) | TXD / R1OUT | **GPIO 17 (TX2)** |
| **信號地 (GND)** | **Pin 3** | Pin 5 (GND) | GND | **GND (共地)** |
| **NTU 發送 (Tx)** | **Pin 4** | Pin 2 (RXD) | RXD / T1IN | **GPIO 18 (RX2)** |

> [!CAUTION]
> **電氣隔離警語**：  
> NTU-1200-112US 輸入端由 12V 大電流鉛酸或磷酸鐵鋰電池供電，逆變全橋開關與 UPS 旁路切換時伴隨嚴重的共模噪訊與地迴路突波。  
> 強烈要求選用**帶光耦隔離與隔離 DC-DC 電源（如 B0505S 隔離晶片）的 RS-232 轉 TTL 模組**，不可使用未隔離的廉價 MAX3232 模組，避免高壓雜訊串入 ESP32 造成畫面撕裂、重啟或晶片損壞。

### 1.2 採購清單與硬體選型

| 項目 | 推薦規格 / 型號 | 說明 |
| :--- | :--- | :--- |
| **主控觸控屏** | ESP32-S3 3.5 吋電容觸控開發板 | 雙核 240MHz, 16MB Flash, 8MB PSRAM, ST7796 480×320 IPS + FT6336U/GT911 |

## 2. 明緯原廠第 5.4 節 RS-232 通訊協定詳解

### 2.1 傳輸層參數
* **串列配置**：9600 bps，8 Data Bits，無同位檢查 (No Parity)，1 Stop Bit (`9600-8-N-1`)
* **編碼格式**：標準 ASCII 字串
* **結束字元**：CR (`0x0D`，即 `\r`)
* **輪詢時序**：
  * **最小請求週期**：$\ge 500\text{ ms}$（嚴格遵守手冊規範）
  * **單筆封包間隔延遲**：$\ge 10\text{ ms}$
  * **逆變器回應時間**：典型 $< 15\text{ ms}$（韌體逾時設定 150ms）

---

### 2.2 核心指令集與封包格式

| 指令 | 類型 | 語法結構 | 說明 |
| :--- | :--- | :--- | :--- |
| **`Q`** | 讀取 (R) | `Q\r` | **狀態查詢 (Status Inquiry)**：讀取即時電壓、負載、溫度、位元旗標 |
| **`I`** | 讀取 (R) | `I\r` | **設備資訊 (Device Info)**：讀取設備型號與韌體版本 |
| **`pU`** | 寫入 (W) | `pU\r` | **參數解鎖 (Parameter Unlock)**：執行輸出電壓切換前必須先解鎖 |
| **`C`** | 寫入 (W) | `C <1/0> [CS]\r` | **輸出控制**：遠端開啟 (`1`) 或關閉 (`0`) 交流逆變輸出 |
| **`W`** | 寫入 (W) | `W <1/0> [CS]\r` | **節能模式**：開啟 (`1`) 或關閉 (`0`) 綠能低功耗模式 |
| **`V`** | 寫入 (W) | `V <WWW> <0FF> [CS]\r` | **輸出配置**：設定輸出電壓與頻率 (例如 `V 110 060 8B\r`) |

---

### 2.3 `Q` 查詢回應資料流結構 (49 位元組資料流)

逆變器回傳之字串格式為小括號包裹、空格分隔之資料封包：
```
(VVV.V QQQ SS.S BBB.B TT.T MMM.M RR.R DDD.D PPP b0b1b2b3b4b5b6b7b8b9b10b11b12b13b14b15b16b17b18)\r
```

範例回傳封包：
```
(110.0 035 035.0 012.6 038.5 110.0 060.0 162.0 000 1011000000000000000)
```

#### 欄位定義表
1. **`VVV.V`** (或 `VVV`): 交流輸出電壓 (AC Output Voltage, 如 `110.0` V)
2. **`QQQ`**: 數位負載百分比 (Output Load Percent, 如 `035` %)
3. **`SS.S`**: 模擬負載百分比 (Analog Load Percent)
4. **`BBB.B`** (或 `BBB`): 直流電池電壓 (Battery Voltage, 如 `012.6` V)
5. **`TT.T`**: 機內散熱器溫度 (Heat Sink Temperature, 如 `038.5` °C)
6. **`MMM.M`** (或 `MMM`): 市電輸入電壓 (Utility Grid Voltage, 如 `110.0` V)
7. **`RR.R`**: 交流輸出頻率 (Output Frequency, 如 `060.0` Hz)
8. **`DDD.D`** (或 `DDD`): 內部直流高壓母線電壓 (DC Bus Voltage, 如 `162.0` V)
9. **`PPP`**: 保留/附屬狀態指標
10. **`b0` ~ `b18`**: 狀態位元旗標字串 (ASCII `0` 或 `1`)：
    * `b0`: **逆變器運作狀態** (`1`: 逆變輸出啟動, `0`: 待機/關閉)
    * `b1`: **UPS 市電旁路狀態** (`1`: 處於市電直通旁路模式)
    * `b2`: **市電正常指示** (`1`: 偵測到市電交流輸入且電壓正常)
    * `b3`: **市電充電致能**
    * `b4`: **太陽能充電致能**
    * `b5`: **節能模式狀態** (`1`: 啟動)
    * `b16`: **逆變器故障旗標** (`1`: 異常 Fault)
    * `b17`: **EEPROM 記憶體錯誤**

### 2.4 NTU-1200-112US 專屬保護門檻（原廠工程參數）

| 監控項目 | 門檻電壓 / 數值 | 系統反應與 UI 行為 |
| :--- | :--- | :--- |
| **正常輸入區間** | 10.0Vdc ~ 16.5Vdc | 儀表量表顯示綠色，運作正常 |
| **低壓警報 (Low Alarm)** | **11.0 ± 0.3 V** | 儀表量表變為橘色，頂部彈出低壓警告 |
| **低壓關斷 (Low Shutdown)** | **10.0 ± 0.3 V** | 儀表量表變為紅色閃爍，系統發出緊急警告 |
| **低壓重啟 (Low Restart)** | **12.5 ± 0.3 V** | 回復正常供電狀態 |
| **高壓警報 (High Alarm)** | **15.5 ± 0.3 V** | 警報提醒電池過壓 |
| **高壓關斷 (High Shutdown)** | **16.5 ± 0.3 V** | 高壓保護切斷 |
| **額定輸出功率** | 1200W (連續) | 負載率 100% |
| **輕度過載保護** | 1380W (115%) | 限制最長 3 分鐘運轉 |
| **峰值湧浪功率** | 2000W | 峰值支援 10 秒 |

## 3. 軟體架構與 FreeRTOS 雙任務設計

為了確保 60 FPS 的絲滑觸控響應，同時嚴格維持明緯協定 500ms 輪詢節拍，系統採用雙核隔離架構：

```
                    ESP32-S3 雙核心 FreeRTOS 排程
      ┌────────────────────────────────────────────────────────┐
      │                        Core 0                          │
      │  ntu_uart_task (明緯協定任務，優先級 3)                  │
      │  ├─ 每 500ms 週期定時發送 "Q\r"                          │
      │  ├─ 150ms 逾時檢測與斷線重試機制                        │
      │  ├─ 命令隊列接收 (如出開關控制、解鎖指令)              │
      │  └─ 互斥鎖 (Mutex) 更新全域結構體 g_ntu_state           │
      └──────────────────────────┬─────────────────────────────┘
                                 │ Thread-Safe Mutex & Queue
      ┌──────────────────────────┴─────────────────────────────┐
      │                        Core 1                          │
      │  gui_task (LVGL 介面與觸控任務，優先級 2)                │
      │  ├─ 每 5ms 呼叫 lv_timer_handler()                     │
      │  ├─ 每 150ms 讀取最新數據並刷新 UI                      │
      │  └─ 觸控中斷取樣 (ST7796 + FT6336U)                    │
      └────────────────────────────────────────────────────────┘
```

## 4. LVGL 觸控介面功能規劃

介面採**現代工業暗黑風格**，專為 480×320 最佳化，具備 5 大導航頁籤：

1. **儀表總覽 (Dashboard)**：
   * 電力潮流動態卡片：市電 110V ──▶ [UPS 旁路] ──▶ AC 輸出 110V (420W)
   * 電池電壓弧形指針：即時顯示 12.6V，依據 11.0V / 10.0V 自動轉為橘色/紅色
   * 負載率圓形量表：即時百分比與瓦數計算 (420W / 1200W)
   * 機內溫度看板：38.5 °C

2. **即時數據 (Telemetry)**：
   * 8 大關鍵電力參數即時數值表
   * 負載率與電池電壓 60 秒即時折線趨勢圖 (LVGL Chart)

3. **控制操作 (Control - 具備安全互鎖)**：
   * **逆變器 AC 輸出開關**：具備二次確認彈窗 (`lv_msgbox`)，避免誤觸斷電導致後端伺服器或負載當機！
   * **綠能節能模式 (Saving Mode)**：一鍵切換 10W 以下 1.5W 待機低功耗模式
   * **輸出電壓/頻率配置**：內建自動 `pU` 解鎖流程

4. **歷史告警 (Alarms & Logs)**：
   * 即時系統狀態橫幅 (正常/低壓/過載/離線)
   * 原廠安全保護設定值與觸發歷史紀錄清單

5. **系統設定與工程診斷 (Settings)**：
   * 螢幕背光 PWM 調光滑桿 (10% ~ 100%)
   * 離線模擬示範開關 (Demo Mode，無接逆變器時可在辦公桌展示完整動態 UI)
   * UART 統計與即時原始 ASCII 封包監視器 (`TX: Q\r` / `RX: (...)`)

## 5. 編譯與燒錄指南

### 5.1 PlatformIO (推薦)
1. 在 VSCode 中安裝 PlatformIO IDE 擴充套件。
2. 開啟本專案目錄 `NTU-1200-112US`。
3. 連接 ESP32-S3 開發板至電腦 USB。
4. 點擊左下角 PlatformIO **Build** 或在終端執行：
   ```bash
   pio run --target upload
   pio run --target monitor
   ```

### 5.2 Arduino IDE
1. 安裝 **esp32 by Espressif Systems** (v2.0.14 或 v3.x)。
2. 安裝程式庫：`lvgl` (8.3.11) 與 `LovyanGFX`。
3. 板子選擇：`ESP32S3 Dev Module`，啟用 `PSRAM: OPI PSRAM`，`Flash: 16MB`。
4. 將 `src/` 中的程式碼移至專案目錄編譯即可。
