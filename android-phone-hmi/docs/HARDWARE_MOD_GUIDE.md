# Android 舊手機硬體改裝與供電工程指南

> **適用設備**：小米 2S (Xiaomi Mi 2S) 與 紅米 Note 11 Pro (Redmi Note 11 Pro)  
> **目標系統**：MEAN WELL NTU-1200-112US 24小時常駐觸控監控控制台

## 2. 小米 2S「假電池外部直供電」改裝要點（強烈推薦！）

小米 2S 採用可拆式電池（型號 BM20，標稱 3.7V / 滿電 4.2V）。若要實現 24 小時 365 天常駐運轉，最穩健做法為**徹底拔除鋰電池芯，採用外部可調 DC-DC 降壓模組直入電池彈片座**。

### 2.1 供電電壓設定 ($4.0\text{ V} \sim 4.15\text{ V}$)
1. **電壓調校**：
   - 使用 LM2596S 或 MP1584EN 可調式降壓模組，將外部輸入（例如 5V 變壓器或 12V 電瓶）降壓調校至 **$4.10\text{ V}$**。
   - 4.10V 在 Android 系統中顯示約 85%~90% 電量，不會觸發過充保護，亦不會引發低電量關機。
2. **抗脈衝大電容**：
   - 手機在開機開屏、Wi-Fi 高速傳輸或 CPU 瞬間滿載時，可能產生高達 **$1.5\text{ A} \sim 2.0\text{ A}$ 的脈衝電流**。
   - **工程要點**：務必在電池座正負極焊點處並聯一顆 **$1000\text{ }\mu\text{F} \sim 2200\text{ }\mu\text{F}$ / $6.3\text{ V} \sim 10\text{ V}$ 的低 ESR 固態或電解電容**，吸收瞬間壓降，防止手機重啟。

### 2.2 電池溫度偵測腳 (B_TEMP / NTC) 處理（關鍵！）
小米 2S 電池座的金屬彈片共有 3~4 個腳位：
- `+` (BATT+)：正極 (接 4.10V)
- `-` (GND/BATT-)：負極 (接地)
- `T` (B_TEMP / NTC)：熱敏電阻腳位。若此腳位懸空，小米 2S 開機數秒內將跳出「電池溫度異常」警告並強制自動關機！

**解決方案（二選一）**：
- **方案 A（最推薦）**：拿一顆廢棄的舊 BM20 電池，小心剪除膨脹的鋁塑電芯並丟棄，保留頂部的**原廠電池保護小電路板 (PCM)**。將 4.10V 電源焊在 PCM 的 B+ 與 B- 輸入端，再將整個模組扣回手機電池座。
- **方案 B**：在手機電池座的 **NTC 腳位與 GND 腳位之間，直接焊上一顆 $10\text{ k}\Omega$ 固定電阻**（10k 阻值模擬電池在常溫 $25^\circ\text{C}$ 的標準狀態）。

### 2.3 解放 Micro-USB 埠為純 OTG
因為電源已經完全由手機後蓋的電池座供給，手機側面的 Micro-USB 埠完全不需要外接任何 Y 型分接供電線！
只需插上一條最普通的 **「Micro-USB 公 轉 USB-A 母」OTG 短線**，即可穩定運作在 USB Host 模式，免除任何供電倒灌或握手協定衝突。

## 3. 紅米 Note 11 Pro「Type-C 邊充邊 OTG」配置要點

若選用紅米 Note 11 Pro，因其為內建不可拆卸電池，需透過 Type-C 連接埠同時達成充電與數據通訊：

### 3.1 供電與傳輸分流配件
- 必須選用**「Type-C OTG 帶 PD 充電二合一轉接器」**。
- 一端插上 $5\text{ V}$ 或 PD 充電器，USB-A 母座端插上「光耦隔離型 USB 轉 RS-232 傳輸線」。

### 3.2 鋰電池長期防膨脹保養策略
鋰電池若長年維持在 100% 滿電且處於充電器發熱環境，極易產氣膨脹：
1. **智慧插座排程**：充電器接在智慧插座上，設定排程（例如充電 1 小時、斷電 2.5 小時循環運作）。
2. **軟體充電上限 (需 Root)**：安裝 ACC (Advanced Charging Controller)，將充電電壓限制在 3.92V、電量上限鎖定在 $60\% \sim 70\%$，可延長鋰電池壽命 4~5 倍。
